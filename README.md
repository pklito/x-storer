### Extension
I wrote this extension to be able to sort my many twitter bookmarks, aswell as automatically backing up their URLs locally.  
This extension is based off this existing extension [XBookmarks](https://chromewebstore.google.com/detail/xbookmark-twitter-bookmar/fmhmeljlbkjibmimlgnijjffmjgbabch?hl=en)
made originally by [Alessandro](https://github.com/alamparelli)

### Features / Improvements:  
- Improved partial rendering for large amounts of tweets at once (tested at ~6000 tweets)
- tweet tagging
  - group tags into the same color
  - hide certain tags by default
  - tag/untag all visible tweets functionality
  - built-in tags for videos, content warning tweets
- save search configurations into tabs
- export saved tweets and config into .json file.
- upload images directly into the system if needed.

### AI Notice:
I don't usually use pure javascript for websites, so this project was done with varying degrees of vibecoding with claude followed by manual rewrites.

### Usage
If you want to install this extension yourself, go to [chrome://extensions/](chrome://extensions/) and load the unpacked folder.
